# Greek

A long-term Ancient Greek learning system founded on Hardy Hansen and Gerald M. Quinn's *Greek: An Intensive Course*.

## Mission

The repository will support the disciplined acquisition of Attic Greek through structured lessons, vocabulary, morphology, syntax, drills, readings, assessment, review, and progress tracking.

The goal is not merely to memorize forms. The goal is to develop the ability to read Greek independently, account for each form morphologically and syntactically, and progress from controlled exercises to continuous Greek prose.

## Foundational curriculum

The primary curriculum is *Greek: An Intensive Course*. Its sequence, terminology, and pedagogical logic govern the first implementation. The repository will preserve the distinction between:

- introduction and pronunciation;
- numbered grammar sections;
- unit vocabulary and vocabulary notes;
- drills and exercises;
- reviews and self-correcting examinations;
- passages from Greek authors;
- appendix and reference materials.

## Repository structure

- `docs/` — charter, architecture, roadmap, and specifications
- `curriculum/` — lessons, vocabulary, grammar, paradigms, exercises, and readings
- `data/` — schemas and validated structured data
- `engine/` — tutoring, assessment, parsing, scheduling, and progress logic
- `tests/` — validation and regression tests
- `tools/` — import, conversion, and maintenance utilities
